# THE LAST KEY

> EVERY ACTION HAS A COST.

키보드의 키가 **한정된 자원**인 퍼즐 플랫포머입니다.
행동에 쓴 키는 그 순간 사용되고, 손을 떼면 영원히 사라집니다.
마우스 없이 키보드만으로 처음부터 끝까지 플레이할 수 있습니다.

- 순수 HTML5 / CSS3 / Vanilla JavaScript / Canvas
- 외부 라이브러리, 이미지, 사운드 파일 없음 (그래픽은 Canvas, 사운드는 Web Audio API로 직접 생성)
- 서버 없이 실행 (`index.html` 더블클릭으로도 실행됨), GitHub Pages 배포 가능

---

## 조작법

| 키 | 기능 |
|---|---|
| `A` | 왼쪽 이동 (누르고 있는 동안) |
| `D` | 오른쪽 이동 (누르고 있는 동안) |
| `SPACE` | 점프 (최대 3칸 높이) |
| `E` | 상호작용 — 문, 레버, 키 보관함 |
| `R` | 되감기 — 3초 전 위치로 돌아감 |
| `ESC` | 일시정지 |
| `ENTER` | 메뉴 확인, 장치(복구 장치/제단) 사용 |
| `↑ ↓ ← →` | 메뉴 이동 (게임 안에서는 행동하지 않음) |

스테이지에 따라 같은 행동을 하는 키가 더 있습니다. 예: `W`도 점프, `L`도 오른쪽 이동.
화면 아래 키보드 UI에 각 키의 행동(← → ↑ USE REW)과 상태가 표시됩니다.

`ESC`, `ENTER`, 방향키는 시스템 키라서 소모되지 않습니다.
키 판별은 `KeyboardEvent.code`(물리 키 위치) 기준이라 한/영 상태와 상관없이 동작합니다.

## 게임 규칙

1. 키를 누르는 순간 그 행동이 수행되고 키가 **사용**됩니다.
2. 누르고 있는 동안에는 행동이 계속됩니다. (`D`를 누르고 있으면 계속 오른쪽으로 걷습니다.)
3. 손을 떼면 그 키는 **영원히 사라집니다.** 키보드 UI에서 어두워지고 금이 갑니다.
4. 행동이 실제로 일어나지 않으면 키는 소모되지 않습니다.
   - 공중에서 누른 점프 (착지 직전이면 예약되었다가 착지 순간 실행)
   - 근처에 대상이 없을 때 누른 `E`
   - 이미 같은 방향으로 이동 중일 때 누른 다른 이동 키
5. 키를 되살리는 방법
   - **떨어진 키캡**: 주우면 그 키를 새로 얻습니다.
   - **키 보관함**: `E`로 열면 새 키가 들어 있습니다.
   - **복구 장치**: 사라진 키 하나를 직접 골라 되살립니다. (1회)
   - **제단**: 남은 키 하나를 바치고, 사라진 키 하나를 되살립니다. (1회)
   - **체크포인트**: 지나갈 때의 키 상태가 기록되어, 실패하면 그 상태로 다시 시작합니다.
6. 가시에 닿거나, 남은 키로 더 이상 나아갈 수 없게 되면 게임 오버입니다. 체크포인트 또는 스테이지 처음부터 다시 할 수 있습니다.
7. 스테이지마다 키가 새로 주어집니다. 진행 상황(해금 스테이지, 체크포인트, 본 엔딩, 설정)은 브라우저 `localStorage`에 저장됩니다.

## 로컬 실행 방법

### 방법 1 — 그냥 열기

`index.html`을 브라우저(Chrome, Edge, Firefox, Safari)로 더블클릭해서 엽니다.
ES 모듈을 쓰지 않는 일반 스크립트 구성이라 `file://`에서도 그대로 실행됩니다.

### 방법 2 — 로컬 서버 (권장)

```bash
# 프로젝트 폴더에서
python -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

VS Code의 Live Server 확장을 사용해도 됩니다.

## GitHub Pages 배포 방법

1. GitHub에서 새 저장소를 만듭니다. (예: `the-last-key`)
2. 이 폴더의 **내용물**(`index.html`이 저장소 루트에 오도록)을 업로드합니다.
   ```bash
   git init
   git add .
   git commit -m "THE LAST KEY"
   git branch -M main
   git remote add origin https://github.com/<사용자명>/the-last-key.git
   git push -u origin main
   ```
   웹에서 올릴 때는 저장소의 **Add file → Upload files**로 폴더 내용을 끌어다 놓으면 됩니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment → Source**를 `Deploy from a branch`로, 브랜치를 `main`, 폴더를 `/ (root)`로 선택하고 Save.
5. 1~2분 뒤 `https://<사용자명>.github.io/the-last-key/` 에서 플레이할 수 있습니다.

모든 경로가 상대 경로라 저장소 이름이 달라도 그대로 동작합니다.

> 참고: Git은 빈 폴더를 올리지 않기 때문에 `assets/images`, `assets/sounds`에는 `.gitkeep` 파일을 넣어 두었습니다. 게임은 이 폴더의 파일을 사용하지 않습니다.

## 모바일

화면은 세로/가로 모두 깨지지 않도록 반응형으로 배치됩니다.
게임 자체는 키보드용이지만, 화면 아래 키보드 UI의 키캡과 `ESC`/`ENTER` 버튼을 직접 눌러도 같은 입력이 들어가고, 메뉴 항목도 터치로 고를 수 있습니다.
